# Liquid Launcher (v0.3)

Jetpack Compose 기반 안드로이드 런처. 홈(4×7) ↔ 앱서랍(왼쪽으로 넘기기), iOS풍 스프링 애니메이션·연속 곡률,
리퀴드 글래스 질감, 배경화면 선택, AOD(대기 화면) 모드.

## v0.3 변경점
- **실제 안드로이드 위젯(AppWidgetHost)**: 홈 빈 곳 길게 누르기 → "위젯 추가" → 설치된 위젯 목록(미리보기·크기 표시)에서 선택
  - 처음 쓰는 위젯은 시스템이 허용 여부를 묻고, 설정 화면이 있는 위젯은 설정 후 배치된다
  - 위젯이 권장 칸 수(Android 12+)를 주면 그대로, 아니면 최소 크기로 4×7 그리드의 차지 칸을 계산
  - 위젯을 길게 누르면 이동 / 제거 (위젯 자체 터치·스크롤은 그대로 동작)
  - 위젯 모서리는 화면 곡률에서 여백을 뺀 값으로 동심원이 되게 잘라 표시
- **아이콘 팩 (GPT 등으로 만든 이미지)**
  - 앱 하나: 앱 길게 누르기 → "아이콘 변경" → 갤러리에서 이미지 선택 (가운데 기준 정사각형으로 잘라 저장)
  - 여러 장: 홈 메뉴 → "아이콘 팩 가져오기" → 이미지를 한꺼번에 선택
    - **파일 이름(확장자 제외)이 앱의 패키지명 또는 앱 이름과 같으면 자동 적용** (예: `com.android.chrome.png`, `카메라.png`)
    - 매칭 실패한 파일 이름은 안내 메시지로 알려준다
  - "기본 아이콘으로" / "아이콘 모두 기본으로" 로 되돌릴 수 있다
  - 이미지는 1024×1024 정사각, 모서리를 둥글리지 않은 꽉 찬 이미지를 권장 (앱에서 같은 곡률로 잘라 준다)

## v0.2 변경점
- **런처 잠금화면 제거**: 폰의 시스템 잠금(지문/PIN)을 그대로 사용한다. (PIN/패턴/제스처/센서 잠금 코드는 삭제됨)
- **AOD(대기 화면) 모드**: 설정에서 켜고 끌 수 있고, 켤 때 번인 위험 안내가 뜬다.
  - **갤럭시 S24 시리즈 이상(모델번호 SM-S921 이상)에서만 켤 수 있다.** 그 외 기기는 스위치가 잠긴다. (`DeviceSupport`)
  - 대기 진입 시간 15/30/60초, 최대 유지 시간 1/3/5/10분, 충전 중에만 사용(기본 켜짐)
  - 시스템 AOD가 아니라 '화면을 켜 둔 채 어둡게 보여주는' 대기 화면이다. 이 모드 동안 폰은 잠금 해제 상태다.
  - 번인 방지: 1분마다 배경화면+시계를 조금씩 이동, 최대 유지 시간 후 자동으로 화면 꺼짐, 터치하면 즉시 해제
- 아이콘은 제조사 마스크 없이 렌더한 뒤 앱에서 같은 곡률(연속 곡률)로 잘라 통일
- 화면 모서리 실제 반지름을 읽어 위젯/여백을 동심원으로 맞춤, 120Hz 선호(대기 화면에서는 해제)

## 빌드
### A) Android Studio
폴더 열기 → Gradle Sync (JDK 17) → Run ▶ 또는 `Build > Build APK(s)`

### B) Codemagic (GitHub에 올린 뒤)
`codemagic.yaml` 포함. 빌드 → APK 아티팩트 다운로드

## 기본 홈 앱 지정
첫 실행 안내에서 "지정", 또는 홈 빈 곳을 길게 눌러 → "기본 홈 앱으로 지정"

## 사용법
- 홈 빈 곳 길게 누르기: 배경화면 / 시계 위젯 / AOD 모드 / 기본 홈 앱
- 앱서랍에서 앱 길게 누르기: 홈에 추가 · 앱 정보 · 삭제
- 홈의 아이콘 길게 누르기: 이동(칸 탭) · 제거

## 구조
- `MainActivity` / `LauncherApplication` : HOME 인텐트, 패키지 변경 리시버, 120Hz 힌트
- `LauncherState` : 앱 목록, 4×7 배치, 배경화면, AOD 상태
- `HomeScreen` / `DrawerScreen` / `LauncherApp` : UI와 페이저·실행 전환 애니메이션
- `AodMode.kt` : 기기 지원 판별(`DeviceSupport`) + AOD 설정/경고 대화상자
- `Aod.kt` : 대기 화면 화면 + 창 밝기/시스템 바 제어
- `Ios.kt` : iOS식 스프링(`iosSpring`), 연속 곡률(`ContinuousCornerShape`)
- `Glass.kt` : 유리 질감, 배경 액체 빛 번짐
- `Widgets.kt` : 위젯 호스트(`WidgetController`), 위젯 표시(`WidgetView`), 위젯 선택 대화상자
- `AppRepository` : 앱 조회, 기본/커스텀 아이콘, 아이콘 팩 가져오기, 실행
